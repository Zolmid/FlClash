## 4. 真正的剩余条件

### 用户已无限期豁免的 V3

用户于 2026-11-16 决定无限期豁免正式 V3 真机与系统网络验收，状态为 USER_WAIVED / NOT_RUN。用户将以实际使用验证。本文档、模拟器记录和 CI 结果都不替代 V3，也不产生 PASS 记录。问题反馈的处理方法见 [设备执行单](device-validation.md) 第 8 节。

### 新正式发行

1.1.10+2026111501 已正式发布并独立核实；main 更新本身不发布 App。新发行须另行核对来源和授权，不得覆盖已发布版本。发布结果及恢复边界见 [CI、发布与恢复](ci-release-and-recovery.md) 第 11 节。

### 远端删除和功能退役

四个历史远端分支已按精确 SHA 删除，PR #3 已关闭；删除前的完整 SHA、去向和恢复依据已记录在分支章节。其余远端分支和没有明确退役决定的产品能力仍保留，后续删除或退役需逐项批准。

### 不构成本轮隐形前置的改进

C 已实现收件箱协调与六项正式 tag 标准检查观察复用，范围和证据见 [架构](architecture.md) 与 [CI](ci-release-and-recovery.md)。其他 routing 拆分、自动 profile 或 debug/release 编译去重仍须具体任务和验收；不能把 C 的局部通过扩大为整库或生产就绪。

## 5. 后续任务如何继续

从当前真实 main 建立隔离工作树，复用仍有效的来源与证据。输入或授权变化只使受影响部分失效，不重做已完成副作用。执行前固定范围、资源、单任务超时与退出方式；全局没有时间截止，单任务超时只结束该任务，不终止总目标。历史消费和预留保留；结尾记录完成项、明确未执行项和可恢复下一动作。

完整操作记录、参考夹具和设备盘点保留在整包本地控制目录；这份可移植手册只包含脱敏结论、公共来源与必要维护规则。
