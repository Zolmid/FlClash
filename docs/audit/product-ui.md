## 应用层缺口闭环与验证边界

首批审查发现的 UI-only 净增量已按第二批所有权补齐：原始 YAML 创建（profile-creation.md）、URL Paste/WebDAV URL 键盘/创建字段 autofocus/TV 输入首次 Back（dialog-inputs.md）、Goroutine 卡片和 Go 内存分类/released 显隐、modal overlay 焦点边界（runtime-ui.md），以及 keyboard-grid owner 的卡片聚焦增删与键盘重排。它们在首批确实不等价，不能改写成“主线原本已有”；当前源码已经有对应实现，最终门禁状态见 root 的 [validation.md](validation.md)。
